# Git y GitHub: práctica individual

Aprende a crear y actualizar tu propio repositorio, añadir archivos y recuperar versiones. No necesitas programar: trabajarás con una ficha sobre un tema que te interese.

Cada persona utiliza **su propio repositorio** y trabaja en `main`.

1. [Preparación: instalar Git y conectar tu cuenta](docs/01-preparacion.md).
2. [Instrucciones y ejercicio individual](instrucciones.md).
3. Elige una ruta: [interfaz gráfica](docs/02-interfaz-grafica.md) o [consola](docs/03-consola.md).
4. [Trabajar desde Google Colab](docs/04-colab.md).

Puedes realizar ambas rutas en el mismo repositorio, con cambios distintos, actualizando la copia local después de trabajar en la web.

## Qué significa cada paso

```text
Editar → Guardar →  add  →  commit  →  push  → GitHub
                   elegir  registrar   subir
```

| Concepto | Para qué sirve |
|---|---|
| Git | Controla versiones en una carpeta local. |
| GitHub | Aloja el repositorio remoto en tu cuenta. |
| Repositorio | Archivos y su historial de cambios. |
| Clonar | Crear una copia local conectada al repositorio remoto. |
| Stage / add | Seleccionar el contenido del próximo commit. |
| Commit | Registrar una versión local con un mensaje. |
| Push | Subir commits al remoto. |
| Pull | Traer e integrar cambios del remoto. |

**Guardar no equivale a hacer commit, y hacer commit no equivale a hacer push.** En la web de GitHub, confirmar una edición crea el commit directamente en el remoto.
